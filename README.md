# 🛠️ GPIO Projects – Learning & Experimenting with Raspberry Pi  

🚀 Welcome to **GPIO Projects**, a collection of **hands-on experiments** using Raspberry Pi's **General Purpose Input/Output (GPIO) pins**.  
This repository is designed for **learning and execution**, allowing you to **play with different components** like **PS2 controllers, LEDs, RGB LEDs, sensors, and more!**  

---

## 📌 **Project Overview**  
This repository contains various **hardware experiments** to help you learn:
- ✅ **LED control** (on/off, PWM brightness, RGB effects)
- ✅ **PS2 controller integration** (reading button inputs, controlling motors)
- ✅ **Sensor interfacing** (ultrasonic, temperature, motion detection)
- ✅ **Motor and servo control** (using L298N motor driver)
- ✅ **Basic automation and real-world applications**  

---

## 📂 **Projects Included**  

### 🟢 **1. LED Blinking & Control**  
- Simple **LED ON/OFF** using GPIO  
- **PWM brightness control**  
- Running **multiple LED patterns**  

### 🌈 **2. RGB LED Control**  
- Changing colors dynamically  
- PWM-based **smooth color transitions**  
- **Sensor-based color adjustments**  

### 🎮 **3. PS2 Controller Integration**  
- Connecting a **PS2 controller** via GPIO  
- Mapping buttons to **control actions**  
- Interfacing with a **motor driver** for real-time motion  

### 🏠 **4. Sensor Interfacing**  
- **Ultrasonic sensor** for distance measurement  
- **DHT11 sensor** for temperature & humidity  
- **PIR motion sensor** for security applications  

### 🚗 **5. Motor & Servo Control**  
- **L298N motor driver** to control DC motors  
- Controlling **servo motors** for robotics projects  
- Building a **remote-controlled car** using PS2 inputs  

---

## ⚙️ **Hardware Requirements**  
- **Raspberry Pi** (any model)  
- **Python 3.x**  
- **Electronic components** (LEDs, resistors, sensors, motors, PS2 controller)  
- **Breadboard & jumper wires**
